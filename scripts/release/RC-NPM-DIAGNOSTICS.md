# #432 bounded npm failure diagnostics

The fake npm 11.20.0 JSON error fixtures in `rc-protected-providers.test.ts` are **modeled shapes**, not captured output from a real npm 11.20.0 `publish --json` invocation. No real CLI `--json` run validated this shape; the publish flags remain unchanged. These fixtures test trusted, code-level parsing of captured process output, not proof of npm's live JSON format or diagnosis of any historical publish failure.

For a nonzero numeric exit with string outputs (and no signal), only exact `error.code` in a bounded JSON object `{ "error": { "code": "..." } }` with optional `summary`/`detail`, or complete anchored stderr lines `npm error code CODE` / `npm ERR! code CODE`, contribute codes. The mapping inherited from #428 is: `ENEEDAUTH` → `NPM_AUTH_REQUIRED`; `E401` → `NPM_REGISTRY_UNAUTHORIZED`; `E404` → `NPM_REGISTRY_NOT_FOUND`; `EUSAGE` → `NPM_CLI_USAGE`; `E_STAGE_REQUIRED` → `NPM_STAGE_REQUIRED`; `EOTP` → `NPM_OTP`; `E403` → `NPM_FORBIDDEN`; `EACCES` / `EPERM` → `NPM_PERMISSION`. No independently verified distinct OIDC/trusted-publisher/environment/provenance code is mapped. Timeout is handled separately; never infer a category from prose.

Any conflicting, unknown or unsupported structured envelope is `NPM_UNKNOWN`, including JSON arrays, primitives and wrong-shaped objects. JSON-looking output beginning (after whitespace) with `{`, `[`, `"`, a digit/`-`, or the whole-word literals `true`, `false`, `null` is rejected if malformed; the same rule applies to stderr. This is deliberately conservative: an ordinary stdout notice such as `npm notice ...` or other prose is *not* structured evidence, so a separate anchored stderr code can still be used. A JSON-looking prose prefix may be rejected even if it was not intended as JSON. Each captured channel is limited to 100,000 UTF-8 bytes; oversize, non-string or ambiguous captures do not confer a category. Failure messages expose only fixed categories, reviewed name/version, capped timings and bounded byte counts, never raw captured text. Publication/reconciliation behavior is unchanged.
