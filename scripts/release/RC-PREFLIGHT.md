# #397 pre-GO read-only bootstrap

`release.yml` first waits for protected `formbar-rc` approval, then uses runner
shell/git to fetch only the generated event's full SHA into an empty repository.
It suppresses git templates, hooks, global/system configuration, redirects and
credential helpers. Its temporary authorization header is passed to **fetch**
only, never stored in `.git/config` or exposed in the remote URL. It verifies
the clean detached HEAD and checks the checked-in bundle against an audited
SHA-256 before invoking runner Node. The bundle uses only Node built-ins and
local #365 read-only source/GO/CI/policy code; it cannot call the OIDC endpoint,
install dependencies or write to npm. The adapter independently repeats all
live checks after preflight and before any irreversible write. Any REST 403,
missing or stale GO, unversioned checkout, or changed policy denies. No GO
exists on current main: approval alone is **not** publish authorization.
